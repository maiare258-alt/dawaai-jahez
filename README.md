# دوائي جاهز

منصة سورية مجانية تساعد المريض على معرفة توفر الدواء في الصيدليات القريبة منه، وعلى معرفة الصيدليات المناوبة، والتواصل مع ممرضين للرعاية المنزلية. انطلقت من مدينة سلمية.

الموقع: https://dawaai-jahez.onrender.com

---

## ما الذي تقدمه المنصة

**للمريض والزائر**
- البحث عن دواء أو مادة فعالة، ومعرفة الصيدليات التي يتوفر فيها، مع البدائل بالمادة الفعالة نفسها.
- قسم لمستحضرات التجميل.
- قائمة الصيدليات المناوبة اليوم وساعات مناوبتها.
- عربة لجمع الأدوية وإرسال طلب إلى الصيدلية، ومتابعة حالة الطلب.
- استشارة صيدلي عبر واتساب.
- دليل ممرضين مع تقييمات المرضى (تُنشر بعد مراجعة الإدارة).
- واجهة بالعربية والإنكليزية، وتعمل على الهاتف، وتعرض صفحة واضحة عند انقطاع الإنترنت.

**للصيدلي (لوحة الصيدلي)**
- تحديث توفر الأدوية وتواريخ الصنع والانتهاء.
- استيراد قائمة أدوية من ملف CSV (حتى 500 صنف في المرة).
- إعلان المناوبة وساعاتها، وساعات الدوام، والإغلاق الاستثنائي.
- استقبال طلبات المرضى وتأكيدها.
- رقم الهاتف ورقم صيدلي مساعد ورقم واتساب وموقع الصيدلية على الخريطة.

**للإدارة (لوحة الإدارة)**
- إضافة الصيدليات والأدوية والممرضين وإدارتها، وجدول المناوبة.
- مراجعة تقييمات الممرضين قبل نشرها، وتوثيق شهاداتهم.
- الإعلانات المحلية، وإحصاءات الزيارات والطلبات، وتقرير ما يبحث عنه المرضى.
- تنزيل نسخة احتياطية كاملة، وفحص حالة النظام.

## التقنيات

| الجزء | التقنية |
|---|---|
| الخادم | Node.js 18 أو أحدث، وExpress 4 |
| قاعدة البيانات | PostgreSQL على Supabase |
| تخزين شهادات الممرضين | Supabase Storage (مجلد خاص) |
| الواجهة | HTML وCSS وJavaScript، بلا أطر عمل ولا خطوات بناء |
| الاستضافة | Render |

```

│   ├── stock.js           توفر الأدوية في كل صيدلية
│   ├── orders.js          طلبات المرضى
│   ├── nurses.js          الممرضون وتقييماتهم وشهاداتهم
│   ├── ads.js             الإعلانات
│   └── stats.js           الإحصاءات والنسخ الاحتياطي والإطلاق الرسمي
├── middleware/
│   ├── adminAuth.js       التحقق من كلمة مرور الإدارة
│   └── rateLimit.js       الحد من المحاولات المتكررة
├── frontend/              الواجهة كاملة (يقدّمها الخادم نفسه)
│   ├── index.html         الصفحة والتنسيق
│   ├── app.js             منطق الواجهة والترجمة العربية والإنكليزية
│   ├── service-worker.js  صفحة انقطاع الإنترنت فقط (لا يخزّن بيانات)
│   ├── offline.html       الصفحة التي تظهر عند انقطاع الإنترنت
```

## متغيرات البيئة

تُضبط في Render من صفحة الخدمة ثم **Environment**. لا تُكتب قيمها في أي ملف داخل المستودع.

| المتغير | الغرض | مطلوب |
|---|---|---|
| `DATABASE_URL` | رابط الاتصال بقاعدة PostgreSQL على Supabase | نعم |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة. إن لم تُضبط تُرفض كل طلبات الإدارة | نعم |
| `SUPABASE_URL` | عنوان مشروع Supabase، لتخزين شهادات الممرضين | لرفع الشهادات |
| `SUPABASE_SECRET_KEY` | المفتاح السري لـSupabase، لتخزين الشهادات | لرفع الشهادات |
| `PORT` | منفذ الخادم. يضبطه Render تلقائياً | لا |

## النشر على Render

- **Build Command:** `npm install`
- **Start Command:** `npm start`
- الجداول تُنشأ تلقائياً عند أول تشغيل، فلا حاجة لأي خطوة يدوية في قاعدة البيانات.
- كل رفع جديد إلى فرع `main` في GitHub ينشر الموقع تلقائياً خلال دقائق.

## التشغيل على جهاز محلي (اختياري)

1. ثبّت Node.js 18 أو أحدث.
2. أنشئ ملفاً باسم `.env` في جذر المشروع، واكتب فيه المتغيرات المذكورة أعلاه، كل متغير في سطر بالصيغة `الاسم=القيمة`. هذا الملف لا يُرفع إلى GitHub أبداً.
3. نفّذ `npm install` ثم `npm start`.
4. افتح `http://localhost:3000`.

## النسخ الاحتياطي

خطة Supabase المجانية لا تأخذ نسخاً احتياطية تلقائية. من لوحة الإدارة، قسم «النسخ الاحتياطي وحالة النظام»، نزّل نسخة دورياً واحفظها في مكان آمن. الملف حساس لأنه يتضمن بيانات الحسابات والطلبات، فلا تشاركه.

## ملاحظات أمنية

- كلمات مرور الصيدليات تُحفظ مشفّرة (bcrypt)، ولا يمكن استرجاعها، بل تُعاد تعيينها من لوحة الإدارة.
- كلمة مرور الإدارة والمفتاح السري لـSupabase موجودان في إعدادات Render فقط.
- مجلد شهادات الممرضين في Supabase يجب أن يبقى خاصاً (غير Public). زر «فحص التخزين» في لوحة الإدارة يتحقق من ذلك.
