# دوائي جاهز

منصة سورية تساعد المريض على معرفة الصيدليات التي يتوفر فيها دواؤه قبل أن يخرج من المنزل، وعلى معرفة الصيدليات المناوبة، وطلب زيارة ممرض للرعاية المنزلية. انطلقت من مدينة سلمية، وهي مصممة لتتوسع إلى كل المدن السورية.

الموقع: https://dawaai-jahez.onrender.com

---

## ما الذي تقدمه المنصة

**للمريض والزائر**
- البحث عن دواء أو مادة فعالة، مع تصحيح الأخطاء الإملائية، ومعرفة الصيدليات التي يتوفر فيها، مع البدائل بالمادة الفعالة نفسها.
- ترتيب محايد للصيدليات في النتائج يتبدّل يومياً، فلا تُفضَّل صيدلية على أخرى.
- قسم لمستحضرات التجميل.
- قائمة الصيدليات المناوبة اليوم وساعات مناوبتها.
- سلة لجمع الأدوية وإرسال طلب إلى الصيدلية، ومتابعة حالة الطلب.
- استشارة صيدلي عبر واتساب.
- دليل ممرضين بخبراتهم ومناطق عملهم وتقييمات المرضى (تُنشر بعد المراجعة)، وطلب زيارة ممرض. رقم الممرض لا يظهر للعامة؛ الطلب يصل إلى مدير التمريض وإلى الممرض نفسه.
- واجهة بالعربية والإنجليزية، تعمل على الهاتف ويمكن تثبيتها كتطبيق، وتعرض صفحة واضحة عند انقطاع الإنترنت.

**للصيدلي (لوحة الصيدلي)**
- تحديث توفر الأدوية وتواريخ الصنع والانتهاء.
- استيراد قائمة أدوية من ملف CSV (حتى 500 صنف في المرة).
- إعلان المناوبة وساعاتها، وساعات الدوام، والإغلاق الاستثنائي.
- استقبال طلبات المرضى وتأكيدها، مع إشعار على الهاتف عند كل طلب جديد.
- رقم الهاتف ورقم صيدلي مساعد ورقم واتساب وموقع الصيدلية على الخريطة.

**لمدير التمريض (لوحة خاصة يدخلها من صفحة الإدارة بكلمة مرور مستقلة)**
- استقبال طلبات الزيارات، مع إشعار على الهاتف عند كل طلب جديد.
- إضافة الممرضين وتعديل خبراتهم ومناطقهم وحالتهم (متاح أو غير متاح).
- مراجعة تقييمات المرضى قبل نشرها.
- إرسال رابط خاص لكل ممرض، وإلغاؤه وإنشاء غيره عند الحاجة.
- لا يحذف ممرضاً، ولا يرى ملفات الشهادات.

**للممرض (صفحة خاصة لا تظهر في قوائم الموقع)**
- تُفتح فقط من رابطه الخاص أو من الإشعار.
- يصله إشعار فور طلبه يذكر منطقة المريض فقط، ويرى في صفحته اسم المريض ورقمه ومكانه والخدمة المطلوبة، ويتصل به مباشرة.
- زر «تواصلت مع المريض» يُظهر للمدير أن الممرض تابع الطلب.

**للإدارة (لوحة الإدارة)**
- إدارة الصيدليات والأدوية والممرضين، وجدول المناوبة.
- ضبط كلمة مرور مدير التمريض ورقمه الذي يظهر للممرضين الراغبين بالانضمام.
- مراجعة التقييمات، وتوثيق شهادات الممرضين.
- الإعلانات المحلية، وإحصاءات الزيارات والطلبات، وتقرير ما يبحث عنه المرضى.
- تنزيل نسخة احتياطية كاملة، وفحص حالة النظام.
- قائمة الممرضين وطلبات الزيارات والتقييمات تتحدث تلقائياً بين الأجهزة المفتوحة في الوقت نفسه.

## التقنيات

| الجزء | التقنية |
|---|---|
| الخادم | Node.js 18 أو أحدث، وExpress 4 |
| قاعدة البيانات | PostgreSQL على Supabase |
| تخزين شهادات الممرضين | Supabase Storage (مجلد خاص) |
| إشعارات الهاتف | Web Push بمعيار VAPID، مبنية داخل المشروع بلا مكتبة خارجية |
| الواجهة | HTML وCSS وJavaScript، بلا أطر عمل ولا خطوات بناء |
| الاستضافة | Render |

الاعتماديات: `bcryptjs` و`compression` و`cors` و`dotenv` و`express` و`pg` فقط.

## متغيرات البيئة

تُضبط في Render من صفحة الخدمة ثم **Environment**. لا تُكتب قيمها في أي ملف داخل المستودع.

| المتغير | الغرض | مطلوب |
|---|---|---|
| `DATABASE_URL` | رابط الاتصال بقاعدة PostgreSQL على Supabase | نعم |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة. إن لم تُضبط تُرفض كل طلبات الإدارة | نعم |
| `SUPABASE_URL` | عنوان مشروع Supabase، لتخزين شهادات الممرضين | لرفع الشهادات |
| `SUPABASE_SECRET_KEY` | المفتاح السري لـSupabase، لتخزين الشهادات | لرفع الشهادات |
| `VAPID_SUBJECT` | عنوان التواصل الذي يُرسل مع الإشعارات. القيمة الافتراضية رابط الموقع | لا |
| `PORT` | منفذ الخادم. يضبطه Render تلقائياً | لا |

مفاتيح الإشعارات (VAPID) تُنشأ تلقائياً عند أول تشغيل وتُحفظ في قاعدة البيانات، فلا تحتاج إلى أي إعداد. كلمة مرور مدير التمريض تضبطها الإدارة من لوحتها، وتُحفظ مشفّرة في قاعدة البيانات.

## النشر على Render

- **Build Command:** `npm install`
- **Start Command:** `npm start`
- الجداول تُنشأ تلقائياً عند أول تشغيل، فلا حاجة لأي خطوة يدوية في قاعدة البيانات.
- كل رفع جديد إلى فرع `main` في GitHub ينشر الموقع تلقائياً خلال دقائق.
- إن فشل نشرٌ ما، يبقي Render النسخة السابقة تعمل، فلا يتوقف الموقع.

## التشغيل على جهاز محلي (اختياري)

1. ثبّت Node.js 18 أو أحدث.
2. أنشئ ملفاً باسم `.env` في جذر المشروع، واكتب فيه المتغيرات المذكورة أعلاه، كل متغير في سطر بالصيغة `الاسم=القيمة`. هذا الملف لا يُرفع إلى GitHub أبداً.
3. نفّذ `npm install` ثم `npm start`.
4. افتح `http://localhost:3000`.

## النسخ الاحتياطي

خطة Supabase المجانية لا تأخذ نسخاً احتياطية تلقائية. من لوحة الإدارة، قسم «النسخ الاحتياطي وحالة النظام»، نزّل نسخة دورياً واحفظها في مكان آمن. الملف حساس لأنه يتضمن بيانات الحسابات والطلبات، فلا تشاركه.

## الخصوصية والأمان

- كلمات مرور الصيدليات ومدير التمريض تُحفظ مشفّرة (bcrypt)، ولا يمكن استرجاعها، بل تُعاد تعيينها من لوحة الإدارة.
- كلمة مرور الإدارة والمفتاح السري لـSupabase موجودان في إعدادات Render فقط.
- أرقام الممرضين لا تظهر للعامة، وعنوان الممرض التفصيلي (الشارع) يراه المدير والإدارة فقط.
- طلبات الزيارات، وفيها أرقام المرضى، تُحذف تلقائياً بعد 30 يوماً.
- الإشعارات لا تحمل اسم المريض ولا رقمه، فلا تظهر بياناته على شاشة القفل.
- رابط الممرض الخاص يمكن إلغاؤه في أي لحظة، فيتوقف فوراً ويتوقف وصول الإشعارات إلى الهاتف القديم.
- مجلد شهادات الممرضين في Supabase يجب أن يبقى خاصاً (غير Public). زر «فحص التخزين» في لوحة الإدارة يتحقق من ذلك.
